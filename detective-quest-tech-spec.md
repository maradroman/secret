# Технічна документація: детективний квест-сайт для подарунка

## 1. Концепція

Сайт-компаньйон до фізичного детективного квесту. Троє окремих сторінок (по одній на кожен етап), кожна відкривається за власним QR-кодом, розміщеним у відповідному фізичному місці. Кожна сторінка приймає текстову відповідь на загадку і, якщо вона правильна, показує одну цифру тризначного коду від кейса із замком.

Ніякого бекенду не потрібно — вся логіка виконується на клієнті (статичний HTML + JS). Хостинг — будь-який статичний хостинг на власному домені користувача.

## 2. Структура сайту

```
/
├── index.html          (опційно: вступна сторінка "Справа №...")
├── case1.html           (етап 1 — пляж)
├── case2.html           (етап 2 — дім)
├── case3.html           (етап 3 — фінал)
├── style.css             (спільні стилі, опційно)
└── assets/
    ├── qr-case1.png
    ├── qr-case2.png
    └── qr-case3.png
```

Кожна `caseN.html` — самостійна сторінка, доступ до якої відбувається лише через QR-код (URL ніде публічно не анонсується), тому додаткова автентифікація не потрібна.

## 4. Логіка перевірки відповіді

Вимоги:
- Нечутливість до регістру (`Пляж` = `пляж` = `ПЛЯЖ`)
- Обрізання пробілів на початку/в кінці (`trim()`)
- Толерантність до дрібних одруків (опційно — рекомендовано для мобільного вводу): допустима відстань Левенштейна ≤ 1

Приклад валідації на чистому JS (без бібліотек):

```javascript
function normalize(str) {
  return str.trim().toLowerCase();
}

function levenshtein(a, b) {
  const dp = Array.from({length: a.length + 1}, (_, i) =>
    Array(b.length + 1).fill(0).map((_, j) => (i === 0 ? j : j === 0 ? i : 0))
  );
  for (let i = 1; i <= a.length; i++) {
    for (let j = 1; j <= b.length; j++) {
      dp[i][j] = a[i - 1] === b[j - 1]
        ? dp[i - 1][j - 1]
        : 1 + Math.min(dp[i - 1][j - 1], dp[i - 1][j], dp[i][j - 1]);
    }
  }
  return dp[a.length][b.length];
}

function checkAnswer(input, correctAnswer, maxDistance = 1) {
  const a = normalize(input);
  const b = normalize(correctAnswer);
  return levenshtein(a, b) <= maxDistance;
}
```

## 5. Шаблон сторінки етапу

Мінімальна робоча структура однієї `caseN.html` (без прив'язки до дизайну):

```html
<!DOCTYPE html>
<html lang="uk">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Справа №1</title>
</head>
<body>
  <p id="riddle">Тут хвилі шепотіли "так" ще до того, як ти це сказала...</p>

  <input type="text" id="answer" placeholder="Твоя відповідь">
  <button id="submit">Перевірити</button>
  <p id="error" style="display:none; color:red;">Не той слід. Спробуй ще раз.</p>

  <div id="result" style="display:none;">
    <p>Правильно! Перша цифра коду: <strong id="digit">X</strong></p>
    <p>Наступний слід шукай там, де...</p>
  </div>

  <script>
    const CORRECT_ANSWER = "пляж";
    const DIGIT = "X"; // підставити реальну цифру

    document.getElementById("submit").addEventListener("click", () => {
      const input = document.getElementById("answer").value;
      if (checkAnswer(input, CORRECT_ANSWER)) {
        document.getElementById("digit").textContent = DIGIT;
        document.getElementById("result").style.display = "block";
        document.getElementById("error").style.display = "none";
      } else {
        document.getElementById("error").style.display = "block";
      }
    });

    // функції normalize / levenshtein / checkAnswer з розділу 4
  </script>
</body>
</html>
```

Аналогічно для `case2.html` (`CORRECT_ANSWER = "дім"`) та `case3.html` (`CORRECT_ANSWER = "Танюшка"`).

## 6. QR-коди

- Кожен QR кодує прямий URL сторінки, напр. `https://вашдомен.com/case1.html`
- Генерація: будь-який безкоштовний онлайн-генератор QR (наприклад, qr-code-generator.com) або бібліотека `qrcode.js`, якщо потрібна автоматична генерація під час збірки
- Роздільна здатність для друку — мінімум 300×300 px, щоб добре сканувався з паперу
- QR-коди зберігаються в `assets/` і друкуються/розміщуються фізично разом із текстом загадки

## 7. Захист від "підглядання" (опційно)

Відповідь та цифра зараз видно у вихідному коді сторінки (`view-source`). Якщо це критично:
- Мінімальний захист: винести `CORRECT_ANSWER` та `DIGIT` в окремий JS-файл і мінімізувати/обфускувати його (наприклад, через `javascript-obfuscator`)
- Практично для цього сценарію (подарунок близькій людині) базового рівня зазвичай достатньо — глибокий захист не потрібен

## 8. Дизайн

Рекомендований стиль — "нуарне досьє": темний фон, друкарський моноширинний шрифт, елементи "штампу" (наприклад CSS-рамка з написом "CONFIDENTIAL" чи "SOLVED" після правильної відповіді). Стилі виносяться в спільний `style.css`, підключений на всіх трьох сторінках.

## 9. Деплой

1. Зібрати всі файли в одну папку за структурою з розділу 2
2. Залити на хостинг через власний домен (будь-який статичний хостинг — Netlify, GitHub Pages, або звичайний shared-хостинг через FTP)
3. Перевірити всі три URL з телефону до фінального друку QR-кодів
4. Роздрукувати QR-коди та розмістити у фізичних місцях згідно таблиці з розділу 3
